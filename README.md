# Layerpilot Studio landing page

A responsive Next.js 15 + React 19 + TypeScript + Tailwind CSS starter for Layerpilot Studio.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Before deploying
- The contact form sends enquiries to `manglvisha@gmail.com` via the visitor's email app.
- Add your LinkedIn profile/company URL.
- Confirm all portfolio descriptions accurately represent your contribution.
- NEXORA is currently presented as a self-initiated demo concept; build it before claiming it as a completed project.
- The contact form currently hands off to the visitor's email app using `mailto:`. It does not store leads. Connect a form backend/service before relying on it.
- Check Vercel plan terms for commercial use before deploying the agency website.

## Deploy
Push this folder to a GitHub repository, import it into Vercel, and use the default Next.js build settings. No environment variables are required.
